# 거상 자동사냥 프로그램 — 설치 및 실행 안내

이 안내서는 처음 설치하시는 분도 순서대로 따라 하실 수 있게 쓰였습니다.
**순서를 건너뛰지 마시고 위에서부터 그대로 따라와 주세요.**

- 준비물: 윈도우 10 또는 11 (64비트), 게임이 설치된 PC
- 소요 시간: 약 20분 (대부분 다운로드 시간입니다)
- 관리자 권한이 필요합니다 (프로그램이 다른 프로그램에 키보드·마우스 신호를 보냅니다)

---

## 1단계 — 프로그램 폴더 내려받기

1. 받으신 `gato_src` 폴더를 **`C:\Gato`** 에 옮겨 주세요.
   - 압축 파일이면 먼저 압축을 풀어 주세요.
   - **폴더 안에 `run_gato.py`, `brain.py`, `assets`, `ui` 가 보여야 정상입니다.**
   - 경로에 한글이나 공백이 섞이면 문제가 생길 수 있으니 `C:\Gato` 처럼 짧게 잡아 주세요.
2. `C:\Gato` 폴더는 **삭제하지 마세요.** 프로그램이 이 폴더 안의 파일을 계속 읽습니다.

> 이미 예전 버전을 받으셨다면, 덮어쓰기 전에 기존 폴더를 백업해 두세요.

---

## 2단계 — 파이썬 설치

1. https://www.python.org/downloads/release/python-3119/ 에 접속합니다.
2. 맨 아래 **Windows installer (64-bit)** 를 받아 실행합니다.
3. 설치 첫 화면에서 **`Add python.exe to PATH`** 를 **반드시 체크**합니다. (제일 중요합니다)
4. `Install Now` 를 누릅니다.
5. 설치가 끝나면 **PC를 한 번 재부팅**합니다.

확인: 윈도우키 → `cmd` 입력 → 엔터 → 검은 창에 아래를 입력해 엔터.

```
py -3.11 --version
```

`Python 3.11.9` 처럼 나오면 정상입니다. 빨간 에러가 나오면 2단계를 다시 해주세요.

---

## 3단계 — 필요한 라이브러리 설치

1. 윈도우키 → `cmd` 입력 → **마우스 오른쪽 클릭 → 관리자 권한으로 실행**
2. 아래 두 줄을 **한 줄씩** 입력하고 각각 엔터를 누릅니다.

```
cd /d C:\Gato
```

```
py -3.11 -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

- 용량이 커서 **5~15분** 걸립니다. 멈춘 것처럼 보여도 기다려 주세요.
- `Successfully installed ...` 가 나오면 성공입니다.
- 빨간 글씨가 잔뜩 나오며 멈추면, **창을 닫지 말고 그 화면을 캡처해서 보내주세요.**

설치 확인:

```
py -3.11 -c "import cv2, torch, win32gui, webview; print('OK')"
```

`OK` 가 나오면 정상입니다.

---

## 4단계 — 화면 설정 맞추기

프로그램은 **1024 × 768** 기준으로 화면을 인식합니다. 게임 화면을 이 크기에 가깝게 맞춰 주세요.

1. 게임을 실행하고 **창 모드**로 바꿉니다.
2. 게임 창 크기를 1024×768 근처로 맞춥니다.
3. 게임 안에서 창 크기 조절 기능이 있으면 그걸 쓰시고, 없으면 윈도우 화면 배율을 **100%** 로 맞춰 주세요.
   - 설정 → 시스템 → 디스플레이 → 배율 및 레이아웃 → **100%**
4. 캐릭터를 **사냥터에 세워 둡니다.**

---

## 5단계 — 실행

1. **게임을 먼저 실행하고 로그인합니다.**
2. 윈도우키 → `cmd` → **관리자 권한으로 실행**
3. 아래를 입력합니다.

```
cd /d C:\Gato
```

```
py -3.11 run_gato.py
```

4. 검은 창에 점검 문구가 나오고, 문제가 없으면 프로그램 창이 뜹니다.

**점검 문구가 나오면 읽어 주세요.** 아래는 각 문구의 뜻과 해결법입니다.

| 나오는 문구 | 뜻 | 해결 |
|---|---|---|
| `Python 3.x is too old` | 파이썬 버전이 낮음 | 2단계 다시 |
| `Administrator rights are required` | 관리자 권한 아님 | cmd를 관리자 권한으로 다시 실행 |
| `The game window was not found` | 게임이 안 켜져 있음 | 게임 실행 후 다시 |
| `A required package is missing` | 라이브러리 설치 안 됨 | 3단계 다시 |
| `asset ... missing` | 폴더 복사가 덜 됨 | 1단계 다시 |

---

## 6단계 — 프로그램 사용

1. 프로그램 창이 뜨면 **몬스터를 고릅니다.** (기본 목록이 들어 있습니다)
2. **시작** 버튼을 누릅니다.
3. 처음 30초는 모델을 불러오느라 **화면이 멈춘 것처럼 보일 수 있습니다.** 기다려 주세요.
4. 실행 중에는 **마우스를 잡지 마세요.** 프로그램이 직접 마우스를 움직입니다.
5. 멈추려면 프로그램 창에서 **정지** 를 누르거나 창을 닫습니다.

## 자주 막히는 곳

**`py` 를 찾을 수 없다고 나옴**
→ 파이썬 설치 시 PATH 체크를 안 하신 경우입니다. 2단계를 다시 하시고 재부팅하세요.

**`pip` 설치 중 빨간 에러**
→ 대부분 관리자 권한 문제입니다. cmd를 관리자 권한으로 다시 열고 3단계를 다시 하세요.

**창은 뜨는데 시작이 안 됨**
→ 화면의 안내 문구를 읽어 주세요. "모델 로드 실패"가 뜨면 3단계 라이브러리 설치가 덜 된 것입니다.

**시작은 되는데 사냥을 안 함**
→ 게임 창이 1024×768과 너무 다르거나, 게임 창이 맨 앞에 있지 않은 경우입니다. 4단계를 다시 확인하세요.

**캡차(자동입력 방지)가 안 넘어감**
→ 캡차 종류별로 화면이 등록되어야 합니다. 캡차 화면을 캡처해서 보내주세요.

## 꼭 지켜주세요

- 프로그램은 **본인 PC에서만** 쓰시고, 폴더를 다른 사람에게 복사해 주지 마세요.
- 실행 중에는 **게임을 최소화하지 마세요.**
- 백신이 파일을 막으면 `C:\Gato` 폴더를 예외 처리해 주세요.
- 잘 안 되면 **검은 창(명령 프롬프트) 화면을 캡처**해서 보내주세요. 그게 가장 빠릅니다.

## 아직 검증되지 않은 부분 (미리 알려드립니다)

이 프로그램은 원본 프로그램의 코드를 복구해서 만든 것입니다. 문법과 파일 구성은 원본과 100% 동일하게 맞췄고, 제 쪽에서는 화면·설정·시작까지 확인했습니다. 다만 아래는 **실제 윈도우 PC에서만 확인 가능**해서, 첫 실행에서 문제가 나올 수 있습니다.

1. 실제 화면 캡처·키보드 입력 같은 윈도우 기능
2. 실제 게임 화면에서의 몬스터 인식
3. 일부 특수한 전투 상황

첫 실행에서 막히면 **정상적인 과정**입니다. 화면을 보내주시면 바로 고쳐 드립니다.
